# اشتراكات اليوم

المدخلات من المالك: تاريخ/تواريخ الاشتراكات، وأي تعديل (وجبات ابو يزيد، تامر، دمج أيام).
الطلبية للشيف = يوم قبل الاشتراكات (اشتراكات الخميس بطلبية الأربعاء). السبت: اشتراكات السبت + الأحد بعمودين (`BOTH=1`).

## الخطوات
1. **تجهيز** (مرة بالجلسة): `bash tools/subs-day/setup.sh` — مجلد شغل جديد: `W=$SUBS_HOME/<التاريخ>` (افتراضياً `/tmp/subs-day`).
2. **سحب تكرار إذا ناقص**: إذا `takrar_suborders` ما فيه التاريخ أو قديم → شغّل workflow `takrar-sync.yml` بمستودع `prohouse-official/prohouse` (ref main) واستنى دقيقة.
3. **البيانات** من `tools/subs-day/queries.sql` (execute_sql) → اكتب بـ `$W`: `subs.json`, `boq.json`, `standing.json`, `orders.json`, `items.json`.
4. **تعديلات المالك**: حدّث `settings.takrar_standing_orders` (وبعدين `standing.json` منه) — مثلاً `days["2026-11-26"] = {meals:[…], extras:[…]}`.
   كل بروتين معه كارب (رز أبيض بنفس الجرامات إذا ما في)، إلا اللي المالك قال "بدون رز".
5. **طلبية الفروع** (إذا طلبها): انسخ نفس اليوم من الأسبوع الماضي (استعلام ٦)، وإذا قال "زود اللي خلص ونقص اللي زاد" استعمل استعلام ٧.
6. **التوليد**:
   ```
   P=$SUBS_HOME/venv/bin/python; T=tools/subs-day
   [إذا وصلت ملفات تكرار] $P $T/labels.py order $W <تكرار1.pdf> [تكرار2.pdf]
   MERGE=1 node $T/build.js $W        # MERGE=1 بس إذا الأيام مدموجة (متل الخميس + الجمعة)
   DATE=<تاريخ الطلبية> node $T/chef.js $W    # BOTH=1 للسبت
   [إذا وصلت ملفات تكرار] $P $T/labels.py labels $W <تكرار1.pdf>:<تاريخ> [تكرار2.pdf:<تاريخ>]
   $P $T/assemble.py $W "اشتراكات_<اليوم>_<التاريخ>.pdf"
   ```
7. **بعات الملف** بـ SendUserFile.

## الترتيب المعتمد للملف
فاتورة الكمية ع → ب → تقرير التغليف ع → ب (مربعات مع الرقم التسلسلي) → ورقة الطلبات الثابتة → ملصقات تكرار (رقم صغير فوق) → طلبية الغد للشيف ع → ب.
كل يوم بصفحاته لحاله، إلا إذا المالك طلب دمج (`MERGE=1`: كل زبون مربع واحد فيه اليومين).

## معيار النجاح — افحصه قبل ما تسلّم
- [ ] كل زبون بملف تكرار موجود بالتغليف، بنفس الوجبات والكارب والحجم (قارن نص الـ PDF مع `subs.json`). أي اختلاف (زبون جديد، وجبة متغيرة) → صلّح `subs.json` و`boq.json` وأعد التوليد، وقول للمالك شو تغيّر.
- [ ] رقم كل مربع = رقم ملصقه (نفس الزبون باليومين نفس الرقم). إذا انضاف زبون بعد نسخة الليل: الأرقام القديمة بتضل، والجديد بياخد رقم بعدها.
- [ ] ما في وجبة بروتين بدون كارب (ما عدا الاستثناءات).
- [ ] ملصق الطلب الثابت: بدون باركود، وبدون جملة "طلب ثابت".
- [ ] طلبية الشيف: أصناف الاشتراكات مدموجة مع صفوف الفروع المطابقة، وأرقام عمود الاشتراكات = مجموع الفاتورة.
- [ ] افتح صفحة التغليف كصورة وتأكد بعينك قبل الإرسال.
